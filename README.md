# HW1
Local When2meet like app to quickly determine meeting times

## Tech Stack Used

- C#
- ASP.NET Core Razor Pages
- HTML
- CSS
- xUnit (For C# unit testing)

## Current Plan
- Creating a table that displays days Monday Through Sunday.
- Using 12-hour time format
- From 12am to 12pm
- When clicked it gets highlighted green/red (indicate availablity)


## Commands for Reference
- Running the web app:
- dotnet run --project .\src\HW1.Web\HW1.Web.csproj
- Refresh with watch:
- dotnet watch --project .\src\HW1.Web\HW1.Web.csproj
